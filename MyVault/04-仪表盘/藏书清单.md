# 📦 藏书清单（拥有的实体/电子书）
## 纸质藏书
```dataview
TABLE WITHOUT ID file.link AS 书, author AS 作者, location AS 位置, price AS 价格
FROM #book
WHERE owned = "physical"
SORT location ASC
```
## 电子书
```dataview
TABLE WITHOUT ID file.link AS 书, author AS 作者, source AS 来源
FROM #book
WHERE owned = "digital"
SORT author ASC
```
