## 藏书概览（实时）
```dataview
TABLE WITHOUT ID
  length(rows) AS 数量
FROM #book
GROUP BY status AS 状态
```

```dataview
TABLE WITHOUT ID length(rows) AS 数量
FROM #book
GROUP BY owned AS 拥有情况
```

## 各分类藏书数
```dataview
TABLE WITHOUT ID length(rows) AS 数量
FROM #book
WHERE category
GROUP BY category AS 分类
SORT length(rows) DESC
```
