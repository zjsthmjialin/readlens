# 📖 我的读书藏书库 · 首页

> 个人读书 / 藏书知识库。需启用 **Dataview** 插件。

## 正在读
```dataview
TABLE WITHOUT ID file.link AS 书, author AS 作者, (progress + "%") AS 进度
FROM #book
WHERE status = "在读"
SORT progress DESC
```

## 最近读完
```dataview
TABLE WITHOUT ID file.link AS 书, author AS 作者, rating AS 评分, finished AS 读完于
FROM #book
WHERE status = "已读"
SORT finished DESC
LIMIT 5
```

## 想读（愿望清单）Top
```dataview
LIST FROM #book
WHERE status = "想读"
SORT added DESC
LIMIT 8
```

## 藏书速览
```dataview
TABLE WITHOUT ID length(rows) AS 数量
FROM #book
GROUP BY status AS 状态
```
